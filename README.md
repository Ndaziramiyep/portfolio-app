# Patrick Ndaziramiye — Portfolio

Personal portfolio website built with React, Vite, Tailwind CSS, and Framer Motion.

🌐 **Live:** [https://nportfolio-lovat.vercel.app](https://nportfolio-lovat.vercel.app)

## Tech Stack

- **React 19** + **Vite**
- **Tailwind CSS** — utility-first styling
- **Framer Motion** — animations
- **React Scroll** — smooth section navigation
- **React Icons** — icon library

## Sections

- Hero — intro, typewriter effect, social links
- About — bio, tech stack highlights
- Skills — categorized skill bars (Frontend, Backend, Mobile, DB, DevOps, Tools)
- Projects — filterable project cards
- Experience — timeline of work history
- Education — degrees & certifications
- Contact — contact form + social links

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build & Deploy

```bash
npm run build   # builds to /dist
```

Deployed on **Vercel** — auto-deploys on push to `main`.
